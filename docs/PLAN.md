# Yuepao 实现计划

个人使用的 iOS 私密记录 App：后宫档案 + 约会/约炮记录 + 地图分布 + 统计。
自签名安装，数据只存在本机。

---

## 0. 关键前提：IPA 怎么来、怎么装

### 0.1 编译
当前开发环境是 Linux，无法直接编译 iOS。采用：

1. 用 **XcodeGen**（`project.yml`）描述工程，不手写 `.xcodeproj`
2. **GitHub Actions macOS runner** 编译，产出**未签名 IPA**
   （`xcodebuild ... CODE_SIGNING_ALLOWED=NO` → 打包 `Payload/Yuepao.app` → `Yuepao.ipa`）
3. 你从 Actions 页面下载 IPA，用自己的方式签名安装

> 如果你有 Mac，也可以直接用 Xcode 打开工程，连手机运行。

### 0.2 签名方式对比

| 方式 | 需要 | 有效期 | 说明 |
| --- | --- | --- | --- |
| 免费 Apple ID + 爱思助手 / Sideloadly / AltStore | Windows 或 Mac 电脑 | 7 天 | 到期要重签；同时最多 3 个自签 App |
| 免费 Apple ID + SideStore | 首次配置要电脑 | 7 天 | 之后可在手机上自己续签 |
| 付费开发者账号（$99/年） | — | 1 年 | 最省心 |
| TrollStore | iOS 14.0–16.6.1 / 16.7 RC / 17.0 | 永久 | 系统版本合适就首选 |
| 第三方证书签名服务 | — | 不定 | 随时掉签，且要把 IPA 交给别人，**不推荐用于这种私密 App** |

### 0.3 数据不丢的规则
- **Bundle ID 永远不改**，续签后**覆盖安装**，数据保留
- **删除 App = 数据全没** → 所以加密备份功能放在第一个功能版本里
- 免费账号用不了 iCloud / CloudKit → 设计为**纯本地**，备份靠导出文件

## 1. 技术选型

| 领域 | 选型 |
| --- | --- |
| UI | SwiftUI |
| 最低系统 | iOS 17（SwiftData、新版 MapKit、Swift Charts 都需要） |
| 存储 | SwiftData |
| 地图 | MapKit；需要点聚合的地方用 `MKMapView`（UIViewRepresentable），SwiftUI `Map` 不支持聚合 |
| 图表 | Swift Charts |
| 解锁 | LocalAuthentication（Face ID / 密码） |
| 加密 | CryptoKit（AES-GCM），密钥存 Keychain |
| 照片 | PhotosPicker，导入后加密存到 App 沙盒，不写入系统相册 |
| 提醒 | UserNotifications 本地通知 |
| 依赖 | 无第三方库、无网络请求、无统计 SDK |

## 2. 数据模型

```
Girl (档案) ──< EncounterParticipant >── Encounter (记录) >── Place (地点)
  │                                          │
  ├──< StatusChange (关系状态历史)            ├──< Expense (花费明细)
  ├──< Memo (时间线备忘)                      └──< Photo
  ├──< Gift (礼物/红包)
  ├──< PeriodRecord (生理期)
  ├──< ImportantDate (重要日期)
  ├──< ContactMethod (联系方式)
  ├──< CustomFieldValue
  └──< Photo
HealthTest (性健康检测，属于自己)
Tag / RankDefinition / CustomFieldDefinition (可自定义的字典)
```

### 2.1 档案 Girl（分组展示，除代号外全部可选）

**A. 基本信息**
- 代号 / 昵称（必填，列表里默认只显示代号）
- 真名（默认隐藏，点击才显示）
- 头像、私密相册
- 生日 → 自动算年龄、星座
- 身高、体重、罩杯 / 三围、体型
- 外貌特征：发型、肤色、纹身、痣等
- MBTI / 性格标签

**B. 社会信息**
- 职业 / 行业、学历 / 学校、籍贯
- 所在城市 + 常驻区域（地图用，可选"精确位置"或"只到区"）
- 感情状况：单身 / 有男友 / 已婚 / 离异
- 联系方式：微信、电话、社交账号（多条）

**C. 认识经过**
- 认识渠道：探探 / Soul / Tinder / 酒吧 / 朋友介绍 / 工作 / 其他（可自定义）
- 认识日期、首次见面日期、介绍人
- 首次发生关系日期（从记录自动算）

**D. 后宫属性（核心特色）**
- **位分**：自定义等级体系，默认一套宫廷风（皇后 / 贵妃 / 妃 / 嫔 / 贵人 / 常在 / 答应），可切换成普通版（女友 / 固定 / 偶尔 / 一次性）
- **关系状态**：撩 / 暧昧中 → 已拿下 → 稳定 → 冷却 → 断联 / 拉黑，每次变化记历史
- **亲密度**：0–100，可手动调，也可按见面频率自动增减
- **评分**：颜值、身材、性格、床上表现、综合（1–10）
- **知情度**：她知不知道你有别人（不知道 / 怀疑 / 知道 / 接受）
- **社交圈交集**：和其他档案的关系（闺蜜、同事、互相认识），避免撞车
- **联系频率目标**：比如"至少 7 天联系一次"，超时进冷落提醒

**E. 偏好与雷区**
- 爱吃 / 忌口、喜欢的饮品、爱好
- 喜欢的礼物 / 品牌
- 雷点、禁忌话题
- **"她说过的事"备忘**：防止人多记混

**F. 亲密偏好**
- 喜欢的体位 / 玩法（多选标签）、敏感点
- 边界 / 明确不接受的
- 避孕约定（必须戴套 / 她吃短效药 / ...）

**G. 健康与周期**
- 生理期记录 + 下次预测

**H. 重要日期**
- 生日、纪念日、自定义日期 → 本地提醒

**I. 时间线**
- 自由备忘流（按时间排列，可插照片）
- 自动汇总：见面次数、上次见面距今天数、总花费

**J. 自定义字段**
- 在设置里加字段（文本 / 数字 / 日期 / 单选 / 多选 / 评分），所有档案通用

### 2.2 记录 Encounter

- **时间**：开始时间、时长、是否过夜
- **参与人**：选 1 个或多个档案（支持多人）
- **地点**：选已有地点，或新建（当前位置 / 地图选点 / 搜索 POI），地点类型：酒店 / 她家 / 我家 / 车 / 户外 / 其他
- **约会内容**：前置活动（吃饭 / 喝酒 / 看电影 / 直接见）、谁主动约的
- **过程**：次数、体位（多选）、玩法 / 道具、她是否高潮（次数）
- **安全措施**：安全套 / 她吃药 / 体外 / 无；是否破套
  → 有风险时自动提醒：72 小时内事后药、检测窗口期
- **花费明细**：酒店、餐饮、礼物、交通 → 汇总进档案"总投入"
- **评分**：满意度、化学反应、心情标签
- 备注、照片（加密）
- **快速记录**：只选人 + 地点 + 时间，几秒存好，之后再补细节

### 2.3 地点 Place
- 名称、类型、坐标、城市 / 区
- 关联记录数（自动算）
- 备注 / 评价（价格、房型、隔音、方便程度等）

### 2.4 其他
- **Gift**：日期、对象、物品 / 金额、场合（生日、节日、红包、转账）
- **HealthTest**：日期、项目、结果、下次检测时间

## 3. 页面结构（底部 5 个 Tab）

1. **后宫**：档案卡片网格（头像、代号、位分、状态、上次见面 N 天前）
   - 排序：位分 / 最近见面 / 次数 / 评分 / 认识时间
   - 筛选：状态、城市、渠道、标签；搜索
2. **记录**：时间线列表 + 日历视图；右上角"+"快速记录
3. **地图**：见第 4 节
4. **统计**：见第 5 节
5. **设置**：解锁、备份 / 恢复、位分 / 标签 / 自定义字段管理、伪装图标

## 4. 地图模块

**图层 1：后宫分布**
- 每个档案在她常驻区域显示**头像标注**
- 边框颜色 = 关系状态或位分（可切换）
- 缩小时聚合，显示"该区域 N 人"

**图层 2：约炮地点**
- 每个地点显示圆点 + **次数角标**，次数越多点越大 / 颜色越深
- 缩小时聚合，显示该区域累计次数

**交互**
- 两个图层可单独看或叠加
- 时间范围筛选：全部 / 今年 / 本月 / 自定义
- 按人筛选：只看某个人相关的地点
- 点标注 → 底部卡片 → 进档案或该地点的记录列表
- **城市面板**：按城市汇总"后宫人数 / 次数"，点亮城市列表

**实现要点**
- `MKMapView` + `MKClusterAnnotation` 做聚合（SwiftUI `Map` 没有聚合）
- **国内坐标偏移**：国内 Apple 地图底图是 GCJ-02，`CLLocationManager` 给的是 WGS-84，直接用会偏几百米。
  方案：优先用地图选点 / POI 搜索拿坐标（本身就和底图一致）；用"当前位置"时做 WGS-84 → GCJ-02 转换。实现时在真机上实测确认。

## 5. 统计模块

- **总览**：后宫人数（按状态分）、累计次数、本月 / 本年次数、本月花费
- **排行**：次数、评分、花费、"性价比"（次数 / 花费）
- **趋势**：按月次数柱状图、星期 / 时段分布、日历热力图
- **渠道分析**：哪个渠道认识的人多、拿下率
- **安全**：无保护次数、上次检测距今天数
- **冷落名单**：超过联系频率目标没见 / 没联系的人

## 6. 隐私与安全

这些数据泄露了对你和对方都是大麻烦，所以按"手机被别人拿到"来设计：

- 启动和从后台回来都要 **Face ID / 密码解锁**
- 进入多任务界面时**模糊遮罩**，截图预览看不到内容
- 数据只在本地，**没有任何网络请求**
- 数据库文件保护等级提到 `Complete`（锁屏时不可读）
- 照片 AES-GCM 加密后存在沙盒里，**不进系统相册**
- 列表默认只显示代号，真名 / 联系方式要点开才显示
- **加密备份**：一键导出带密码的备份文件到"文件" App，可导入恢复
- **伪装**：App 显示名在编译时设定（比如叫"记账本"），图标可在 App 内切换成普通图标
- iOS 18 以上可以再叠加系统自带的"需要面容 ID"和"隐藏 App"
- （可选，后期）紧急模式：输入特定密码显示空数据
